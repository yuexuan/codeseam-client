CodeSeam 0.5.1 - Local Windows Environment Preflight

Source history: https://github.com/yuexuan/codeseam-client
Based in part on Z-Switch (MIT). Original copyright and LICENSE retained.
Legacy server code based on Sub2API (LGPL-3.0) is archived separately and is
not included in this desktop application or installer.

This first draft contains read-only local preflight and recovery of known
managed configuration backups. No CodeSeam cloud account, API relay, service
activation, portal or billing service is required. No user account, API key
or proxy password is bundled. Claude login remains in official applications.

Known encrypted backups use Windows CurrentUser DPAPI in
%LOCALAPPDATA%/CodeSeam. Unknown formats, decryption failures or external
configuration conflicts are reported; backups are retained. Recovery requires
confirmation. Uninstall stops when unresolved managed records remain.

This release does not implement the remaining five setup stages, a production
baseline, Guest management, or complete process network protection. Installed
applications and detected configuration are not claims of verified routing.
No upstream updater or cloud telemetry is enabled.

Includes Mihomo v1.19.34 (GPL-3.0), bundled as a separate executable.
